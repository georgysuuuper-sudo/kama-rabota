# Кама.Работа

**Свежие нормальные вакансии в Перми — без мусора и развода.**

Статический сайт, который показывает вакансии с hh.ru по Перми за последние 7 дней
с зарплатой от 50 000 ₽, уже очищенные от скама, МЛМ, «дропов», гео-обманок
и неподходящих профессий. Подходит парню 20 лет без опыта: любая честная работа —
руками, головой, в сервисе, удалённо или подработка.

**Живая версия:** <https://georgysuuuper-sudo.github.io/kama-rabota/>

## Что это и как работает

Сайт полностью статический (GitHub Pages не запускает сервер), поэтому данные
готовятся заранее и кладутся в репозиторий как JSON:

```
GitHub Actions (cron, каждые 6 часов)
   └─► Python-скрапер: запрашивает hh.ru → фильтрует → считает рейтинг доверия
          └─► сохраняет data/vacancies.json + data/meta.json
                 └─► коммитит файлы в репозиторий
                        └─► GitHub Pages отдаёт index.html, который читает JSON
```

- **Сборщик:** Python 3.11+, только `requests` + стандартная библиотека.
- **Сайт:** чистые HTML + CSS + JavaScript, без фреймворков и сборки.
- **Автоматизация:** `.github/workflows/update.yml` (cron `0 */6 * * *`,
  ручной запуск, push в `main`) + деплой на GitHub Pages.

### Структура

```
├─ index.html               # единственная страница
├─ assets/
│  ├─ style.css             # стиль «Kama Noir», светлая/тёмная темы
│  ├─ app.js                # фильтры, сортировка, избранное, карточки
│  ├─ fonts.css + *.woff2   # локальные шрифты Onest и Unbounded (кириллица)
│  ├─ ornament.svg          # авторский орнамент пермского звериного стиля
│  ├─ favicon.svg, og.png   # иконка и превью для соцсетей
│  └─ screenshot.jpg        # скриншот для README
├─ data/
│  ├─ vacancies.json        # отфильтрованные вакансии (читает сайт)
│  └─ meta.json             # дата обновления, счётчики, причины отсева
├─ scraper/
│  ├─ fetch_hh.py           # сбор: API → запасной HTML-разбор, кэш, дедуп
│  ├─ filters.py            # жёсткие условия, стоп-листы, категории, сниппеты
│  ├─ trust_score.py        # рейтинг доверия 0–100 по таблице ТЗ
│  ├─ config.py             # ВСЕ пороги и стоп-слова в одном месте
│  └─ selftest.py           # автотест приёмки (запускается и в CI)
└─ .github/workflows/update.yml
```

## Запуск локально

```bash
# 1. собрать данные (нужен интернет; ходит на hh.ru аккуратно, с паузами)
pip install requests
python scraper/fetch_hh.py

# 2. поднять сайт
python -m http.server 8000
# открыть http://localhost:8000
```

Полезные флаги скрапера:

| Флаг | Что делает |
|---|---|
| `--offline` | пересчитать выдачу из кэша `scraper/.cache/raw.json`, без сети |
| `--source api\|html\|auto` | принудительно официальный API или HTML-разбор |
| `--pages N` | максимум страниц на один проход поиска |
| `--limit-details N` | сколько карточек догружать с полным описанием |
| `--no-details` | не догружать описания (быстрее, но рейтинг грубее) |
| `--min-trust N` | порог рейтинга доверия для публикации |

После любого прогона можно проверить выдачу автотестом:

```bash
python scraper/selftest.py
```

Он проверяет: гео (Пермский край), свежесть ≤ 7 дней, зарплату ≥ 50 000 ₽,
отсутствие стоп-слов, рейтинг доверия, уникальность id, ссылки на hh.ru
и отсутствие личных данных / полных описаний. Код возврата 1 = провал.

## Как поменять фильтры

Все списки и пороги лежат в **`scraper/config.py`**:

- `MIN_SALARY`, `PERIOD_DAYS`, `AREA_ID`, `INCLUDE_REMOTE` — жёсткие условия;
- `GENDER_STOP_WORDS`, `GENDER_REQUIREMENT_PATTERNS` — стоп-лист профессий
  и явных требований к полу; нейтральные слова (`парикмахер`, `повар`,
  `продавец`, `бариста`, `официант`) сами по себе **не** режутся;
- `MANUAL_REVIEW_PATTERNS` — спорные случаи уходят в «проверить вручную»
  и в выдачу не попадают;
- `SCAM_STOP_WORDS`, `SOFT_STOP_WORDS` — скам и тревожные формулировки;
- `PERM_LOCALITIES`, `GEO_OTHER_STEMS` — гео-фильтр (вахты в другие регионы
  hh помечает как «Пермь», поэтому адрес рабочего места проверяется отдельно);
- `TRUST_WEIGHTS`, `TRUST_MIN`, `TRUST_MIN_RELAXED`, `MIN_VACANCIES` — рейтинг
  доверия и правило «если вакансий мало, ослабить порог до 50»;
- `CATEGORIES` — ключевые слова категорий «Руками / Головой / Сервис / …».

После правки прогоните `python scraper/fetch_hh.py --offline` и
`python scraper/selftest.py`, чтобы увидеть эффект без повторных запросов к hh.ru.

## Публикация на GitHub Pages

1. Создайте публичный репозиторий и запушьте этот проект в ветку `main`.
2. `Settings → Pages → Build and deployment → Source: GitHub Actions`.
3. Workflow `.github/workflows/update.yml` уже настроен: он собирает данные,
   коммитит `data/*.json` (сообщение с `[skip ci]`, чтобы не зациклиться)
   и деплоит сайт через `actions/deploy-pages`.
4. Первый запуск можно сделать вручную: `Actions → «Обновление вакансий и деплой»
   → Run workflow`.
5. Ссылка появится в `Settings → Pages` и в README выше.

### Токен hh.ru (если понадобится)

Скрапер сначала пробует **официальный API** `api.hh.ru`. Если API начнёт требовать
токен приложения — зарегистрируйте приложение на `dev.hh.ru` и добавьте токен
в `Settings → Secrets and variables → Actions → New repository secret`
с именем **`HH_TOKEN`**. В код токен не пишется: workflow передаёт его через
переменную окружения. Без токена скрапер автоматически переходит на запасной
HTML-разбор выдачи `perm.hh.ru` (медленнее, но работает).

## Данные и дисклеймер

- Источник данных — **hh.ru**. Сайт не связан с hh.ru и не является его продуктом.
- Мы не копируем описания целиком: только короткий сниппет и ссылку на оригинал.
- Контакты работодателей и персональные данные не собираются и не хранятся.
- Рейтинг доверия — эвристика, а не гарантия. **Всегда проверяйте работодателя сами.**
- **Никогда не платите за трудоустройство и не передавайте данные банковских карт.**

Нагрузка на hh.ru бережная: паузы 0.3–0.9 с между запросами, повторы с
экспоненциальной задержкой на 429/5xx, кэш сырых записей, чтобы не ходить
лишний раз. Пожалуйста, не уменьшайте паузы и не запускайте сбор чаще расписания.
